# 🛡️ Security Policy

Thank you for helping improve the security of **NeuroSOC**.

NeuroSOC is an **AI-assisted Security Operations Center (SOC) & SIEM platform** developed for **authorized defensive security, security operations, education, and cybersecurity research.**

---

## 📌 Supported Versions

| Version | Supported |
|:--------:|:---------:|
| Latest Release | ✅ Yes |
| Development Branch | ✅ Active |


---

## 🚨 Reporting a Security Vulnerability

If you discover a security vulnerability in **NeuroSOC**, please report it responsibly and **avoid public disclosure** until the issue has been reviewed and resolved.

Please include:

- A clear description of the vulnerability
- Steps to reproduce
- Expected vs. actual behavior
- Impact assessment
- Proof of Concept (if applicable)
- Suggested remediation (optional)

Responsible disclosure helps protect users and allows sufficient time for investigation and remediation.

---

## 🔒 Secure Deployment

For production or shared environments, we recommend:

- Enable authentication and role-based access control (RBAC)
- Restrict dashboard and API access to trusted networks
- Protect API keys, secrets, and environment variables
- Use HTTPS with valid TLS certificates
- Regularly update project dependencies
- Enable audit logging and monitor system activity
- Keep the application behind a firewall or reverse proxy

NeuroSOC is intended solely for:
