# 🤝 Contributing to NeuroSOC

Thank you for your interest in contributing to **NeuroSOC**! Whether you're fixing bugs, improving documentation, enhancing features, or optimizing performance, every contribution is appreciated.

---

## 🚀 Getting Started

1. **Fork** this repository.
2. **Clone** your fork locally.
3. Create a new feature branch.

```bash
git checkout -b feature/your-feature-name
```

4. Install the project dependencies and start the development environment by following the setup instructions in the **README.md**.

---

## 🧪 Before Submitting

Please ensure your changes:

- ✅ Pass all backend and frontend tests
- ✅ Follow the project's coding standards
- ✅ Include relevant documentation updates
- ✅ Maintain clean, readable, and modular code
- ✅ Do not introduce breaking changes unless clearly documented

---

## 📌 Pull Request Guidelines

When opening a Pull Request, please include:

- A clear summary of the changes
- The motivation behind the contribution
- Related issue number (if applicable)
- Screenshots or examples (when relevant)

Small, focused pull requests are preferred over large unrelated changes.

---

## 🐞 Reporting Issues

Found a bug or have a feature request?

Please open a GitHub Issue and include:

- Environment details
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots

---

## ⚖️ Code of Conduct

By contributing to **NeuroSOC**, you agree to follow the guidelines outlined in **CODE_OF_CONDUCT.md** and help maintain a welcoming, respectful, and collaborative open-source community.

Thank you for helping make NeuroSOC better! 🚀
